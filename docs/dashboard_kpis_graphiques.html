1 · Dashboard Principal

Vue globale

Le dashboard principal agrège toutes les sources connectées (Gmail, Slack, Jira, ClickUp, Outlook…) en une vue unifiée. Il est organisé en 4 onglets : Vue d'ensemble, Alertes & Risques, Décisions, Équipe & Système. Un filtre de période (Aujourd'hui / 7j / 30j / 90j) s'applique à tous les indicateurs.

◈ Vue d'ensemble 🚨 Alertes & Risques ✅ Décisions 🧠 Équipe & Système
Indicateurs Clés de Performance (KPIs) — Vue d'ensemble
📦
Messages totaux
data.total_items
Nombre total de messages synchronisés depuis toutes les sources sur la période sélectionnée. Sert de dénominateur pour les taux (risque, sentiment, NLP).
Cliquable → drill-through "Répartition par source"
🔗
Sources connectées
connected_sources / total_sources
Ratio entre les sources ayant renvoyé des données et le total configuré. Une source est "active" si elle a au moins 1 message dans la période.
Ex : 3/7 → 3 sources actives sur 7
⚠️
Alertes critiques
data.critical_alerts
Nombre de messages NLP-classifiés comme Blocked, Urgent, Risk ou Conflict avec un score de priorité élevé. Déclenche le badge rouge sur l'onglet Alertes.
🔴 > 5 = Critique 🟡 2–5 = Modéré 🟢 0–1 = Faible
🎯
Indice de risque
data.risk_index / 100
Score composite (0–100) calculé à partir du taux de messages à risque, du score de burnout moyen, du nombre d'escalades et du sentiment négatif global.
🔴 > 60 = Critique 🟡 30–60 = Modéré 🟢 < 30 = Faible
⚡
Signaux de risque
intel.risk_count
Nombre de messages portant au moins un label à risque (Blocked, Urgent, Risk, Conflict, Overload, Concern). Comptage direct des sorties NLP.
> 10 = Élevé 4–10 = Moyen 0–3 = Faible
⚡
Vélocité hebdomadaire
velocity.this_week vs velocity.last_week
Volume de messages reçus cette semaine comparé à la semaine précédente. La flèche ↑/↓ indique la tendance en pourcentage. Utile pour détecter les pics d'activité.
Δ% = (cette_sem − sem_passée) / sem_passée × 100
😊
Sentiment positif
sentiment.positive %
Pourcentage de messages classifiés POSITIVE par le modèle NLP de sentiment (CamemBERT fine-tuné). Un score élevé indique un climat de communication sain.
Complémentaire : neutral + negative = 100%
📉
Sentiment négatif
sentiment.negative %
Pourcentage de messages classifiés NEGATIVE. Un taux élevé peut signaler des tensions, des blocages ou de la frustration dans les équipes ou chez les clients.
> 30% = Critique 15–30% = Attention < 15% = Normal
🧠
Couverture NLP
intel.nlp_coverage %
Taux de messages qui ont été analysés par le pipeline NLP (business label + sentiment + émotion). Un taux < 80% signifie que certains messages ne sont pas encore traités (sync en cours).
> 80% = Excellent 50–80% = Partiel < 50% = Sync requis
⭐
Source principale
argmax(by_source)
La source ayant généré le plus de messages sur la période. Indique où se concentre l'activité de communication du CEO (ex : Gmail 142 msgs).
🚩
Items à risque
intel.at_risk_items.length
Nombre de messages identifiés comme nécessitant une attention immédiate du CEO — combinaison d'un label risqué ET d'un score de priorité élevé.
> 5 = Critique 2–5 = Attention 0–1 = Normal
📊
Taux de risque global
intel.risk_rate % = risk_count / total_items × 100
Proportion de messages à risque sur l'ensemble des messages analysés. C'est le KPI le plus synthétique de la santé communicationnelle de l'organisation.
> 30% = Critique 15–30% = Modéré < 15% = Sain

2 · Dashboard Gmail

Gmail

Accessible via /dashboard/gmail. Analyse approfondie des emails — threads, temps de réponse, escalades, désalignements. Même structure 4 onglets que le dashboard principal.

KPIs Gmail
📥
Gmail (semaine)
volume.this_week · Δ% vs last_week
Emails reçus cette semaine vs semaine précédente. La flèche verte ↑ / rouge ↓ indique la tendance.
🔴
Non lus
unread.count · unread.rate %
Emails INBOX non lus (sans label READ). Le taux = non_lus / total_inbox × 100.
> 40% = Critique 20–40% = Attention < 20% = Normal
⭐
Importants
important.count · important.rate %
Emails avec label IMPORTANT (marqués par Gmail ou Google AI). Taux = important / total × 100.
⚡
Temps de réponse moyen
avg_response_hours (heures)
Calculé en associant chaque email INBOX avec le premier email SENT du même thread qui le suit. Exprimé en heures. "N/A" si le dossier Envoyé n'est pas synchronisé.
< 2h = Réactif · 2–24h = Normal · > 24h = Lent
🚨
Escalades
escalation.count
Emails contenant les mots-clés : urgent, ASAP, critique, bloqué, immédiatement, escalade. Détecté par regex dans le sujet + corps.
> 5 = Critique 2–5 = Modéré 0–1 = Normal
⏰
Sans réponse +48h
no_reply_48h.count
Emails IMPORTANT reçus il y a plus de 48h sans aucun email SENT dans leur thread. Ces emails nécessitent une action immédiate du CEO.
> 5 = Urgent 2–5 = Attention
❗
Critiques sans réponse
unanswered_critical.count
Intersection entre escalades (mots-clés urgence) et sans réponse +48h. Ce sont les cas les plus critiques — escalade reçue ET ignorée.
≥ 1 = Risque critique 0 = OK
🔁
Threads longs
threads.long_count · threads.avg_length
Nombre de threads Gmail ayant plus de 3 messages. Un thread long indique souvent un sujet non résolu ou un désalignement entre parties. avg_length = longueur moyenne de tous les threads.
> 5 = Surveillance 0–5 = Normal
↔️
Back-and-forth score
threads.back_and_forth_score / 10
Intensité des échanges : proportion de threads avec plus de 2 aller-retours × 10. Un score élevé signale des conversations longues et potentiellement conflictuelles.
> 6/10 = Intense 3–6 = Modéré < 3 = Faible
👤
Expéditeurs uniques
unique_senders
Nombre d'adresses email distinctes ayant envoyé au moins un message dans la période. Indicateur de la diversité du réseau de contact du CEO.

INBOX · SENT · IMPORTANT · STARRED…
🍩 DonutChart
Répartition des labels natifs Gmail sur les emails synchronisés. Couleurs : IMPORTANT = orange, STARRED = bleu, SENT = vert, SPAM = rouge, DRAFT = gris.
Données : data.label_distribution
Tendance des risques
Évolution des labels à risque
📈 LineChart (rouge)
Même graphique que le dashboard principal, filtré sur Gmail. Affiche l'évolution des messages Blocked/Urgent/Risk jour par jour.
Pic d'activité par heure
Répartition horaire 6h–22h

Histogramme du volume d'emails par heure de la journée (plage 6h–22h). Permet d'identifier les heures de pointe et les messages reçus hors horaires.

🚨 Emails d'escalade — action requise
Liste des emails contenant des mots-clés d'urgence (urgent, ASAP, critique…). Fond rouge, bordure gauche rouge. Chaque item montre le titre, l'expéditeur et l'horodatage.

3 · Dashboard Outlook

Outlook
🔴
Non lus
unread.count · unread.rate %
Emails Outlook non lus sur la période. Même calcul que Gmail mais basé sur l'API Microsoft Graph (isRead=false).
⭐
Haute importance
high_importance.count · rate %
Emails avec importance = "high" ou "urgent" dans les métadonnées Microsoft. Équivalent Outlook de "Important" dans Gmail.
📎
Pièces jointes
attachments.count · attachments.rate %
Emails contenant au moins une pièce jointe. Indicateur spécifique Outlook pour identifier les échanges de documents importants.
🚨
Escalades Outlook
escalation.count
Même détection par mots-clés que Gmail (urgent · ASAP · critique) mais appliquée aux emails Outlook/Exchange.

5 · Signaux NLP — Labels Business

IA · NLP

Chaque message est classifié par le moteur NLP (CamemBERT + règles métier) dans l'un de ces 8 labels. Affiché dans le SignalPanel présent sur tous les dashboards.

🔴
Blocked
Message signalant un blocage opérationnel : quelqu'un est bloqué, un projet est arrêté, une ressource manque. Priorité maximale.
🟠
Urgent
Demande d'action immédiate, délai critique, deadline imminente. Mots-clés : urgent, ASAP, deadline, EOD.
🟡
Risk
Signale un risque identifié : financier, technique, client, légal. N'est pas encore une urgence mais doit être surveillé.
🟣
Conflict
Désaccord entre parties, conflit d'équipe, tension interpersonnelle. Nécessite une médiation ou une décision du CEO.
🔴
Overload
Signal de surcharge de travail pour une personne ou une équipe. Indicateur de burnout potentiel.
🟡
Concern
Préoccupation exprimée sans urgence immédiate : inquiétude, questionnement, besoin de clarification.
🟢
Progress
Message positif signalant une avancée, une validation, un succès. Bon signal de dynamique d'équipe.
⚪
Neutral Update
Information neutre, compte-rendu, mise à jour sans impact décisionnel. Représente la majorité des messages dans un contexte sain.

6 · Composants communs (tous dashboards)

Priority Inbox
Top 8 messages prioritaires de la semaine
📋 Liste interactive
Les 8 messages avec le score de priorité le plus élevé. Score = f(urgence, sentiment, label, heure). Clic → MessageDetailModal avec génération de brouillon IA, labels NLP, et fonctionnalité de correction des labels.
Risk Feed
Signaux de risque détectés
⚠️ Feed filtré
Liste des messages avec au moins un label à risque (Blocked, Urgent, Risk, Conflict). Affiche le label, l'auteur et la date. Filtrable par label.
Signal Panel
Distribution des 8 labels business
📊 Tableau de bord
Vue d'ensemble de tous les labels NLP avec leur comptage, leur % et un graphique mini. Cliquable pour filtrer les messages par label.
Burnout Card
Score de surcharge par collaborateur
🔥 Score + classement
Score de burnout (0–10) calculé pour chaque collaborateur à partir du volume de messages hors horaires, du sentiment négatif et des labels Overload. Affiché seulement si données disponibles.
Anomaly Card
Anomalies détectées par Isolation Forest
🤖 ML · Isolation Forest
Anomalies détectées dans les patterns de communication : pics anormaux de volume, sentiment inhabituellement négatif, heure d'envoi atypique. Modèle entraîné en arrière-plan par le ML Scheduler.
ML Status Card
État des modèles IA en production
🧠 Monitoring
Affiche le statut de chaque modèle ML (NLP, Isolation Forest, émotion) : dernière exécution, précision, nombre d'items traités, erreurs éventuelles.
Ask Anything
Chatbot RAG · Question en langage naturel
🤖 LLM + RAG
Permet au CEO de poser une question en français sur ses données (ex : "Quels sont les sujets bloquants cette semaine ?"). Le LLM (Ollama) utilise un retriever RAG (TF-IDF) pour trouver les passages pertinents dans les messages.
MessageDetailModal
Détail d'un message + actions
🗂️ Modal
Modal s'ouvrant au clic sur n'importe quel message. Affiche : source, auteur, date, labels NLP, analyse IA, contenu. Pour Gmail : bouton "Générer une réponse" (LLM), éditeur de brouillon, envoi avec pièces jointes, correction des labels (continuous learning).

7 · Codes couleur & Seuils globaux

Niveaux de risque
🔴 HIGH (Critique) — Nécessite une action immédiate du CEO
🟡 MEDIUM (Modéré) — À surveiller, plan d'action à prévoir
🟢 LOW (Faible) — Dans les normes, aucune action requise

Filtres de période

Tous les KPIs et graphiques se recalculent à la sélection d'une nouvelle période.

Architecture des données (flux)
1. Sync → Connectors (Gmail API, Outlook Graph, Slack API…) → ItemStore
2. NLP Pipeline → Sentiment (CamemBERT) + Business Label (règles) + Émotion (XLM) + Topic
3. Analytics Engine → Calcul des KPIs, tendances, threads, scores
4. ML Scheduler → Isolation Forest (anomalies) + Fine-tuning continu
5. API FastAPI → /api/analytics/overview · /api/analytics/{source} · /api/emails/draft
6. Frontend Next.js → Dashboards, KPICards, Charts, Modals
